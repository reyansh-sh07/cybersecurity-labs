# SQL Injection

This directory groups PortSwigger Web Security Academy exercises focused on SQL injection.

## Labs

| Lab | Vulnerability focus | Status |
|---|---|---|
| [SQL Injection — WHERE Clause Allowing Retrieval of Hidden Data](../07-sql-injection-where-clause-hidden-data/) | SQL injection / hidden data retrieval | Solved |

## Focus areas

- Understand how application input can alter SQL query logic.
- Recognise injection points in application requests.
- Practise safely in intentionally vulnerable training environments.
- Document the test approach, observations, impact, and remediation.

All exercises are performed in authorised labs.
