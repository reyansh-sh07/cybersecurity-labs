# SQL Injection

PortSwigger Web Security Academy labs focused on SQL injection flaws.

## Labs

| Lab | Vulnerability focus | Status |
|---|---|---|
| [WHERE Clause Allowing Retrieval of Hidden Data](./00-sql-injection-where-clause-hidden-data/) | SQL injection / hidden data retrieval | Solved |

## Focus areas

- Understand how application input can alter SQL query logic.
- Recognise injection points in application requests.
- Practise safely in intentionally vulnerable training environments.
- Document testing approach, observations, impact, and remediation.

All exercises are performed in authorised labs.
