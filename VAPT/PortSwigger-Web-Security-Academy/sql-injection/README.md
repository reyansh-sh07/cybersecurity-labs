# SQL Injection

PortSwigger Web Security Academy labs focused on SQL injection flaws.

## Labs

| Lab | Vulnerability focus | Status |
|---|---|---|
| [01 — WHERE Clause Allowing Retrieval of Hidden Data](./01-sql-injection-where-clause-hidden-data/) | SQL injection / hidden data retrieval | Solved |
| [02 — Login Bypass](./02-sql-injection-login-bypass/) | SQL injection / authentication bypass | Solved |
| [03 — Database Version Disclosure (Oracle)](./03-sql-injection-database-version-oracle/) | UNION-based SQL injection / database fingerprinting | Solved |

## Focus areas

- Understand how application input can alter SQL query logic.
- Recognise and test injection points in requests.
- Practise UNION-based injection and database fingerprinting.
- Document the testing approach, observations, impact, and remediation.

All exercises are performed in authorised labs.
