# Authentication

PortSwigger Web Security Academy exercises focused on authentication weaknesses and bypasses.

## Labs

| Lab | Vulnerability focus | Status |
|---|---|---|
| [Password Reset Broken Logic](./00-password-reset-broken-logic/) | Password-reset workflow / account takeover | Solved |
| [2FA Simple Bypass](./01-2fa-simple-bypass/) | Multi-factor authentication bypass | Solved |

## Focus areas

- Examine authentication workflows and their state transitions.
- Check how password-reset tokens and account identifiers are validated.
- Understand the difference between first-factor authentication and completed MFA.
- Test alternate navigation and request paths in authorised lab environments.

All exercises are performed in intentionally vulnerable training labs.
