# Broken Access Control

PortSwigger Web Security Academy labs focused on authorization and access-control weaknesses.

## Labs

| Lab | Vulnerability focus | Status |
|---|---|---|
| [Unprotected Admin Functionality](./01-unprotected-admin-functionality/) | Unprotected administrative functionality | Solved |
| [User Role Controlled by Request Parameter](./02-user-role-controlled-by-request-parameter/) | Client-controlled role / vertical privilege escalation | Solved |
| [User ID Controlled by Request Parameter](./03-user-id-controlled-by-request-parameter/) | IDOR / horizontal privilege escalation | Solved |
| [User Role Can Be Modified in User Profile](./04-user-role-can-be-modified-in-user-profile/) | Mass assignment / vertical privilege escalation | Solved |

## Focus areas

- Identify missing or ineffective server-side authorization checks.
- Distinguish horizontal and vertical privilege escalation.
- Understand how user-controlled identifiers and role values can lead to unauthorized access.
- Validate access controls in authorised lab environments.

All exercises are performed in intentionally vulnerable training labs.
