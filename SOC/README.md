# Security Operations Centre (SOC)

This directory contains defensive-security projects focused on monitoring, investigation, analysis, digital forensics, and detection.

## Projects

| Project | Focus | Status |
|---|---|---|
| [SOC01 — SSH Authentication Log Investigation](./SOC01-authentication-log-investigation/) | Linux SSH authentication analysis using a self-generated synthetic dataset | Completed |
| [SOC02 — Compromised Windows Analysis](./SOC02-compromised-windows-analysis/) | Windows DFIR, persistence, execution artefacts, event logs, and timeline reconstruction | Completed |
| [SOC03 — Phishing Unfolding (SOC Simulator)](./SOC03-phishing-unfolding-simulator/) | Unguided phishing-incident scenario and alert triage | In progress |

## Project Standards

- Clearly identify synthetic, simulated, guided, and real-world data.
- Record the investigation workflow, evidence, and reasoning.
- Separate observed facts from hypotheses and conclusions.
- State limitations and identify evidence needed for further validation.
- Never publish credentials, session tokens, challenge flags, or sensitive operational data.
