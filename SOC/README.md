# Security Operations Centre (SOC)

This directory contains defensive-security projects focused on monitoring, investigation, analysis, and detection.

## Projects

| Project | Focus | Dataset | Status |
|---|---|---|---|
| [SOC01 — SSH Authentication Log Investigation](./SOC01-authentication-log-investigation/) | Linux SSH authentication analysis, suspicious-source triage, and evidence-based incident assessment | Self-generated synthetic logs | Completed |

## Project Standards

- Clearly identify synthetic, simulated, and real-world data.
- Record the commands and reasoning used during an investigation.
- Separate observed facts from hypotheses and conclusions.
- State limitations and identify evidence needed for further validation.
- Never publish credentials, session tokens, or sensitive operational data.
